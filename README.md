# Godomcoworld

Godomcoworld is an educational and marketplace platform built for the Pi Network ecosystem.

The app focuses on AI-powered learning and skill development, offering digital courses in Web3, Blockchain, Industrial Revolutions, and vocational skills such as welding, carpentry, tailoring, fashion design, hair styling, and leather goods production.

Godomcoworld also includes Africa-focused marketplaces where farmers, artisans, and small producers can showcase and sell their products using Pi payments.

This repository is used for domain verification and web presence for the Godomcoworld Pi App while the main application is developed and maintained within Pi App Studio.

Official Pi App: Godomcoworld  
Network: Pi Testnet (preparing for Mainnet)
